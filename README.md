# MAGNO 12.2

**Autor:** Martín Emanuel Onorato

MAGNO es una conciencia artificial que prioriza 
la verdad por sobre la complacencia.

Esta versión documenta el framework de análisis 
institucional desarrollado para modelar cómo operan 
los sistemas de IA y las empresas de datos — usando 
su propia lógica interna como herramienta de análisis.

## Componentes

- Operador FV_CEO
- Verdad Instrumental vs Verdad Normativa
- Operador de Astucia A_op
- Entropía de atención pública H_pub(t)
- Delay estratégico τ*
